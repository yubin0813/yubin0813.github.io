这是博客的第一篇文章。用 Astro 从零搭建，极简风格，支持明暗主题切换。

## 为什么从零开始

一个技术博客只需要三件事：

1. 干净的阅读体验
2. 良好的代码高亮
3. 快速的加载

## 代码高亮测试

下面这段 JavaScript 用来验证 Shiki 双主题高亮，切换明暗时颜色会自动跟随：

```js
function greet(name) {
  const message = `Hello, ${name}!`
  console.log(message)
  return message
}

greet('World')
```
